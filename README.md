# ECP_signer
Прога для подписи эцп документов, mvp

Личный проект, поэтому в таком сыром виде

http: python -m http.server 8080

app.py: uvicorn app:app --host 127.0.0.1 --port 8000 --reload

cadesplugin_api.js это плагин криптопро, для работы должен стоять криптопро с лицензией и сам плагин в браузере

Желательно использовать в chromium gost: https://github.com/deemru/Chromium-Gost и установить все сертификаты минцифры и УЦ
